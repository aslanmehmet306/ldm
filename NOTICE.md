# Notice

**Independent implementation notes. Not affiliated with or endorsed by IATA.**

This repository documents implementation patterns and carrier-specific variations observed in live
IATA Type B message traffic, together with an independently written parser and validation logic.

It does not reproduce or replace the applicable IATA manuals or standards. It contains no element
tables, format notation, mandatory/conditional status definitions, or worked examples taken from
any published specification. Every example message in this repository was constructed for it and
is synthetic.

For authoritative specifications — formal element definitions, status, and format notation — consult
the officially licensed IATA publications. The Load Distribution Message is defined in the Airport
Handling Manual; service and special-load codes are defined separately in the same series.

The intent of this material is to be **complementary** to those publications rather than a
substitute for them. A specification tells you what carriers are supposed to send. These notes
record what they actually send, which is knowledge a specification cannot carry.
