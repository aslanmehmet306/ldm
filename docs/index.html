Independent implementation tool. Not affiliated with or endorsed by IATA. It does not reproduce or replace the applicable IATA manuals or standards. For authoritative specifications, consult the officially licensed publications — the LDM is defined in the Airport Handling Manual.

Implements parsing rules written from message behaviour observed in live Type B traffic, published as the ldm-message-parsing skill. Coverage is deliberate rather than exhaustive: real traffic contains carrier-specific shapes not represented here. If you have a message it mishandles, that is the interesting case.

Everything runs client-side. No message you paste is transmitted, stored or logged, and no fonts, scripts or analytics are loaded from anywhere — which is why this page uses system typefaces.
